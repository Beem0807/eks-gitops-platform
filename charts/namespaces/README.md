# namespaces

Centralized namespace management — creates namespaces with optional ResourceQuotas

![Version: 1.0.0](https://img.shields.io/badge/Version-1.0.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square)

## How it works

The chart loops over `.Values.namespaces` and renders one `Namespace` per entry. Labels and annotations are merged — global values apply to every namespace and per-namespace values win on key conflicts.

If `resourceQuota` is provided (globally or per namespace), a `ResourceQuota` named `default` is created inside that namespace. Per-namespace quota overrides the global default entirely.

```
global.labels          ─┐
global.annotations     ─┤─▶ applied to all namespaces
global.resourceQuota   ─┘

namespaces[*].labels        ─▶ merged on top of global.labels
namespaces[*].annotations   ─▶ merged on top of global.annotations
namespaces[*].resourceQuota ─▶ overrides global.resourceQuota entirely
```

## Usage

Reference `charts/namespaces` in an ArgoCD ApplicationSet and pass the namespace list as Helm values:

```yaml
source:
  repoURL: https://github.com/Beem0807/eks-gitops-platform.git
  targetRevision: main
  path: charts/namespaces
  helm:
    releaseName: cluster-namespaces
    values: |
      namespaces:
        - name: monitoring
          resourceQuota:
            requests.cpu: "4"
            requests.memory: 8Gi
            limits.cpu: "8"
            limits.memory: 16Gi
        - name: simple-time-service
        - name: logging
```

### Adding a new namespace

Add an entry to the `namespaces` list in `gitops/namespaces/cluster-namespaces.yaml`. ArgoCD self-heals and creates the namespace on the next sync.

### Adding a ResourceQuota

Set `resourceQuota` on the namespace entry. The `namespaces` ArgoCD project allows `ResourceQuota` in all namespaces, so no project changes are needed:

```yaml
- name: simple-time-service
  resourceQuota:
    requests.cpu: "2"
    requests.memory: 4Gi
    limits.cpu: "4"
    limits.memory: 8Gi
```

## Values

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| global.annotations | object | `{}` | Annotations applied to every namespace. Per-namespace annotations are merged on top. |
| global.labels | object | `{"app.kubernetes.io/managed-by":"argocd","app.kubernetes.io/part-of":"eks-gitops-platform"}` | Labels applied to every namespace. Per-namespace labels are merged on top — per-namespace wins on key conflicts. |
| global.resourceQuota | object | `{}` (no quota by default) | Default ResourceQuota applied to every namespace unless overridden at the namespace level. Leave empty to skip quota creation. |
| namespaces | list | `[]` (no namespaces created by default) | List of namespaces to create. Each entry supports per-namespace `labels`, `annotations`, and `resourceQuota` overrides. |
